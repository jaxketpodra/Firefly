## 从剧本到世界

普通 RP：模型扮演一个角色，陪你演一段对手戏。
沙盒 RP：模型扮演**整个世界**——时间流动、NPC 有自己的生活、你的行动有后果。

差别在哪？剧本 RP 里模型只需要"接下一句"；沙盒里模型要回答的问题是"**这个世界接下来会发生什么**"。

这是两种完全不同的提示词设计思路。

## 核心思想：状态机，不是故事线

写沙盒提示词时，把自己当成游戏策划而不是编剧：

❌ 编剧思维（脆弱）：
```
第一天邻居姐姐来借酱油，你们认识了。
第二天她在楼道里跟你打招呼……
```
模型看完只会照本宣科，玩家一偏离就崩。

✅ 策划思维（健壮）：
```markdown
# 世界规则
- 时间按回合推进，一天分早/中/晚
- 每个 NPC 有自己的日程表和动机
- NPC 不会主动贴上来，关系按玩家的行动逐步变化

# NPC：林雪（邻居姐姐）
- 25 岁，自由插画师，昼伏夜出
- 动机：赶稿期缺钱，对邻居保持礼貌距离
- 好感度 0-20：点头之交 | 20-50：会借东西聊几句 | 50+：主动敲门
```

区别：**不给剧情，给规则和动机**。剧情是模型根据规则现算的——玩家做什么都接得住。

## NPC 自主性：动机大于台词

让 NPC"活"的秘诀是给他们**独立于玩家的生活**：

```markdown
- 没有玩家在场时，NPC 也在过自己的生活（赶稿、上班、和别的朋友聚会）
- NPC 对玩家的态度由共同经历决定，不是一见钟情
- NPC 之间会互相交流，产生玩家不知道的事
```

一个反例提醒：很多玩家喜欢"全员倒贴"的开局，但那种世界两轮就腻了——**有阻力的世界才有粘性**。慢热的核心是"关系变化必须有迹可循"。

## 随机与判定

纯模型生成的"随机"是假的（它会挑最合理的选项）。引入真随机：

```markdown
# 判定规则
玩家的非常规行动需要判定：
1. 投掷 D20（1-20 随机数）
2. 判定结果 = D20 + 相关属性修正
3. ≥15 成功，<15 失败，大成功/大失败触发特殊事件
```

让模型"生成一个 1-20 的随机数并严格按结果叙事"。不完美（模型的随机数分布不均），但比没有强得多——关键是**判定结果对模型自己也是约束**，它必须服从骰子。

## 状态持久化：沙盒的命脉

沙盒最大的敌人是遗忘。第 02 篇讲过注意力衰减——50 轮后模型早忘了你第一天借过酱油。

解法只有一种：**状态外化 + 每轮注入**。

```markdown
【世界状态】
第 3 天 傍晚 | 地点：公寓楼道
林雪：好感度 34/100 | 状态：赶稿中，两天没出门
已知情报：她周五要交稿 | 冰箱里没菜了
```

每轮由系统更新、随提示词注入。模型不需要"记得"，只需要"读到"。这套机制我们在自家 RP 引擎里就是这么做的——对话负责生动，状态负责连续。

## 小结

- 沙盒 = 规则 + 动机，不是剧本
- NPC 有自己的生活，关系要玩家挣
- 随机判定让结果对模型也有约束力
- 状态外化是对抗遗忘的唯一解
